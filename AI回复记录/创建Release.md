
**我建议下一步先做 `创建 Release`，它极其简单，而且很有仪式感。**

操作步骤：
1. 在仓库首页右侧边栏，找到 **Releases**，点击 **Create a new release**。
2. 点击 **Choose a tag**，输入 `v1.0.0`，然后点击 **Create new tag**。
3. Release title 写：`v1.0.0 - 初版上线`。
4. 描述里写：`完成了 GitHub Playground 的基础搭建，开通了 Pages，学习了 Issue 和 PR 流程。`
5. 点击 **Publish release**。

发布后，你的仓库首页右侧会多出一个醒目的 `Releases v1.0.0` 标签。这就像给你的项目打上了一个“里程碑”印章。
