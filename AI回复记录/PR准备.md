
### 🚀 步骤一：把当前分支推送到 GitHub
直接点击左侧那个蓝色的 **`发布 Branch`** 按钮。VS Code 会在 GitHub 上自动为你创建同名的远程分支。

### 🚀 步骤二：补上 `hobbies.md` 文件
1. 在左侧文件列表的空白处右键 -> **New File**。
2. 命名为 `hobbies.md`。
3. 写点内容（比如你的爱好），保存（`Cmd+S`）。
4. 再次打开源代码管理面板：点 `+` 暂存 -> 输入提交信息 `feat: 添加爱好列表` -> 点对勾提交 -> 点“同步更改”推送。

### 🚀 步骤三：去网页端发起 Pull Request
1. 打开你的 GitHub 仓库网页。
2. 由于你刚推送了分支，网页顶部通常会弹出一个绿色的 **`Compare & pull request`** 按钮，点击它。
3. **标题**可以写：`添加爱好列表`。
4. **描述框里务必写上**：`Closes #1` （注意：看你刚才 Issue 建好后编号是几，如果是 #2 就写 #2）。
5. 点击 **`Create pull request`**。

### 🚀 步骤四：合并 PR 并见证奇迹
1. 在 PR 页面点击 **`Merge pull request`**，然后 **`Confirm merge`**。
2. 点击删除分支的按钮（`Delete branch`，表示这个功能分支已经合并完，可以功成身退了）。
3. **去 Issues 标签页看看**：你之前的那个 Issue 应该已经自动变成 `Closed` 状态了！
4. **去 Projects 看板看看**：这张卡片应该自动移到 `Done` 或者 `Closed` 列了。

### 🚀 步骤五：回到本地同步 main
1. 回到 VS Code。
2. 点击左下角的 `feature/add-hobbies`，选择切换回 `main` 分支。
3. 点击源代码管理面板的“刷新”或“同步更改”，把远程合并后的最新代码拉下来。

完成这一套操作，你就正式通关了**分支、提交、推送、PR、合并、自动关闭 Issue**这条最核心的协作链路！去点“发布 Branch”，然后补上 `hobbies.md` 吧！
